# Nuottikokoelmat

Tablet/Mobile/Desktop application.
Music score archives for multiple archives/bands for making collections to be used as concert or practice set lists.
Supports url based music score location such as Google drive or photos, and can use downloaded files as local music score cache.

## Nuottikokoelmat-api

Alternative backend for the score archives.

## Nuottikokoelmat-data

Fetching music scores from various services into a data-service,
that provides the score files for authenticated users.

## SimpleDrive

A4 paper showing the starts of songs in few sizes.
Memory game showing the starts of the songs for wanted seconds.
Simple PDF music score archive and tablet browser.
