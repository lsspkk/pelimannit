# Pelimannit

Here's some apps for folk musicians. With MIT licence, hope that this code can be useful for someone.
If it is, please let me know. Thanks.

## Nuottikokoelmat

Tablet/Mobile/Desktop application.
Note archives for multiple archives/bands for making collections to be used as concert or practice set lists.
Supports url based note location such as Google drive or photos, and can use downloaded files as local note cache.

# Nuottikokoelmat-api

Alternative backend for the note archives.

## SimpleDrive

A4 paper showing the starts of songs in few sizes.
Memory game showing the starts of the songs for wanted seconds.
Simple PDF note archive and tableet browser.
